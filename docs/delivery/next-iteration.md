- 认证撤销标记与服务断言防重放记录迁入 MySQL，使用 Flyway V1.11；当前语义见[认证运维](../runbooks/authentication-operations.md)。
- 商品发现、限时活动、登录、商品详情和个人 / AI 工作区的界面更新，补充桌面与移动浏览器回归。
- 8 件多品类演示商品、持久化媒体与规格、后台编辑、图片放大，以及助手推荐、对比和购买草稿的连续流程，见[验收记录](../quality/shopping-experience-2026-10-02.md)。

- 真实容器上的桌面与手机产品验收、购物助手提示与仓库展示调整，见[产品验收记录](../quality/product-acceptance-2026-10-02.md)。
- 完整 CI 的 Qdrant 与应用默认版本对齐，增加版本一致性检查，并复验索引、alias 切换与检索；公开演示命令统一，见[维护记录](../quality/maintenance-alignment-2026-10-02.md)。
- 审计开放字段兼容和库存守恒去重等既有修复保留历史红绿证据，见[历史证据索引](../quality/evidence-index-2026-09-16.md)。

## 仍需推进

| 优先级 | 主题                     | 下一步与验收依据                                                                                                                                                               |
| ------ | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| P1     | 真实性能基线             | 历史 5000 requested RPS 目标未达。分开测量登录成本和持有 JWT 的预约路径，在固定资源、持续负载与可复核数据下报告完成量、dropped、P95/P99 和库存事实；不将短窗口除法当稳态吞吐。 |
| P2     | Refresh 轮换与浏览器中断 | 用慢网、页面跳转和多标签竞争复现轮换响应丢失，明确恢复体验，同时保留 family 重放检测。历史现象需要在当前版本复测。                                                             |
| P2     | 对账的持续推进与空间     | fence 持续变化会重启扫描，seen 随唯一预约增长。验证稳定水位、分段核算与可审计历史保留方案，在持续写入下保持公平推进和真实异常检测。                                            |
| P2     | 知识检索与真实模型       | 扩展中英问题与改写评测，定位历史瞬时 RetrievalError；真实模型和百炼向量分别在明确配置与预算下评测。不得用降低阈值掩盖无关引用。                                                |
| P2     | 活动重装语义             | 对已售出、多活动、普通购买并存和已补偿场景设计活动版本 / 剩余配额规则，验证不增发库存、不覆盖有效预约。                                                                        |
| P2     | 流式连接与进程恢复       | 测量订单 SSE 轮询与连接成本；明确 Agent 进程重启、慢客户端、断线和取消的产品行为，再决定持久化与跨实例协调方案。                                                               |

| P3     | 首次构建与缓存           | 根 Dockerfile 的完整仓库 COPY 影响缓存。记录另一台空缓存机器的拉取、构建、启动时间后，再优化构建上下文和缓存层。                                                               |

历史 Windows shell 换行、时区与生成客户端差异在相关报告中保留。是否仍能复现应以当前脚本和一次完整运行判定，不能直接继承旧的失败或通过结论。所有新结论记录受测提交、命令和环境，统一收录到[证据索引](../quality/evidence-index.md)。
